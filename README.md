# -
Описание:
Приложение состоит из трех основных мини-игр:
- Текст в одну строчку — печать коротких фраз с подсветкой текущей буквы
- Полный текст — печать многострочных текстов с отслеживанием прогресса
- Тетрис с буквами — падающие буквы, которые нужно успевать нажимать

Возможности:
- Поддержка русского и английского языков
- Разные жанры
- Возможность добавлять собственные тексты
- Настройка используемых букв в тетрисе (по пальцам или вручную)
- Визуальная клавиатура-подсказка
- Статистика по всем режимам
- Звуковые эффекты при ошибках

Управление:
  В режимах печати:
  - Любая буква/символ — ввод текста
  - Пробел / Enter — ввод пробела / переноса строки
  - Esc — выход в главное менюы
  В тетрисе:
  - Буквы на клавиатуре — уничтожение падающих букв

Статистика
Приложение отслеживает:
- Количество пройденных текстов/игр
- Скорость печати (знаков в минуту)
- Процент ошибок
- Лучшие/последние результаты


Установка и запуск:
- Установите Python 3.7+
- Скачайте или склонируйте репозиторий:
- git clone https://github.com/ваш-username/название-репозитория.git или скачайте ZIP-архив и распакуйте
- Откройте терминал/командную строку в папке с проектом
- Установите необходимые библиотеки:
  1) pip install pygame
  2) pip install Pillow
- Запустите программу: python "! Проект.py"
- Для создания .exe файла (необязательно):
  1) pip install pyinstaller
  2) pyinstaller --onefile --windowed --add-data ".txt;." --add-data ".mp3;." --add-data "pechat.png;." "! Проект.py"
